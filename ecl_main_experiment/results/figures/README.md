# Figure Output Structure

Generated by `models/analysis/create_comparison_figures.py` (run from `ecl_main_experiment/`).

The top-level `results/` folder is parallel to `eda/` and `models/`:

- `results/raw_metrics/` stores per-model result CSV files.
- `results/figures/` stores generated figures.
- `results/summary_tables/` stores aggregate CSV summaries used by the figures.

## model_diagnostics/

Single-model forecast and error plots generated by each training script.

## performance_comparison/

Model accuracy and forecast-horizon comparison figures:

- `figure_1_rq1_rmse_by_horizon.png` — RQ1, RMSE change across horizons.

## cost_efficiency/

Accuracy-cost trade-off figures:

- `figure_2_rq2_accuracy_vs_training_time.png` — RQ2, accuracy-cost trade-off.

## robustness_checks/

Sensitivity and robustness figures:

- `figure_3_client313_robustness.png` — Critical Evaluation, with/without Client 313 robustness check.

## business_decision_support/

Client-facing model selection and recommendation figures:

- `figure_5_model_selection_decision_matrix.png`
- `figure_6_accuracy_cost_complexity_bubble.png`
- `figure_7_business_scenario_recommendations.png`

## interpretability/

English-annotated interpretability figures for the project deliverable and RQ3 framing:

- `rq3_interpretability_method_matrix.png`
- `rq3_interpretability_readiness.png`

## Note on Figure 4

A Client 313 multi-model prediction overlay is not included. Result CSVs store
metrics only; per-client forecast arrays are not exported by the training
scripts. An actual-vs-predicted time series figure is available in the weather
extension experiment (`ecl_weather_covariates_experiment/outputs/figures/weather_extension/fig_07_actual_vs_predicted.png`).
